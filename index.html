Installer le capteur de capacité

LOLIN S2 Mini (ESP32-S2) · Chrome ou Edge sur ordinateur, Windows ou macOS

  1. Brancher la carte au PC avec un câble USB (câble de données).
  2. Passer la carte en mode boot : maintenir 0, appuyer brièvement sur RST, relâcher 0.
  3. Cliquer ci-dessous sur le bouton Installer qui correspond à votre radio.
  4. Choisir le port de la carte dans la liste (nom contenant « ESP32-S2 », ou un port COM sous Windows), puis suivre les écrans.
  5. Une fois l'installation terminée, appuyer sur RST pour démarrer.

Choisir la version

FlySky

Télémétrie iBus, courant sans correction.

Navigateur non compatible : utiliser Chrome ou Edge. La page doit être ouverte en HTTPS.

Futaba / FrSky

Télémétrie SBUS2, courant sans correction.

Navigateur non compatible : utiliser Chrome ou Edge. La page doit être ouverte en HTTPS.

Futaba / FrSky ×1,18

Télémétrie SBUS2, courant corrigé ×1,18.

Navigateur non compatible : utiliser Chrome ou Edge. La page doit être ouverte en HTTPS.

Entre les deux versions Futaba : commencer par 100 %, passer à 118 % si le courant affiché est environ 18 % trop faible par rapport à une mesure de référence.

En cas de problème

  • Aucun port dans la liste : refaire le passage en mode boot, changer de câble USB, essayer un autre port USB sans hub.
  • Erreur pendant l'installation : débrancher, rebrancher, recharger la page et recommencer depuis l'étape 2. Fermer tout logiciel qui utilise le port (Arduino IDE, moniteur série).
  • La carte ne démarre pas : recommencer l'installation en acceptant l'effacement complet quand il est proposé.
